# Kekulawala Advertising — Company Website

Official marketing website for **Kekulawala Advertising** (Since 1982), an indoor & outdoor
signage solutions company based in Kurunegala, Sri Lanka.

A fast, modern, fully responsive single-page site built with **Vite + vanilla HTML/CSS/JS** —
no heavy framework, no build-time surprises.

## ✨ Features

- Premium dark navy brand theme with the company's blue / cyan / green / parrot palette
- Sticky glass header with scroll-spy navigation and mobile slide-in menu
- Cinematic hero with brand banner, Sinhala wordmark (කැකුලාවල) and animated counters
- Auto-scrolling services marquee
- Services grid with pointer-tracking glow (Outdoor Advertising, Digital Printing,
  Laser Cutting & Engraving, 3D & LED Signage, Vehicle Branding, Exhibition & Display)
- Filterable project portfolio with a full-screen lightbox (keyboard & touch friendly)
- Photorealistic, AI-enhanced project imagery across all service categories
- Process timeline, testimonials, animated stat counters
- Working quote-request form with client-side validation (hands off to email/WhatsApp)
- Google Maps embed, click-to-call, WhatsApp deep link and QR code
- SEO ready: meta tags, Open Graph image, JSON-LD `LocalBusiness` schema, semantic HTML
- Accessible: focus states, ARIA labels, reduced-motion support, responsive down to small phones

## 🚀 Getting Started

```bash
npm install      # install dependencies
npm run dev      # start dev server (http://localhost:5173)
npm run build    # production build into dist/
npm run preview  # preview the production build
```

## 🗂 Project Structure

```
├── index.html               # Page markup & content
├── vite.config.js           # Vite configuration
├── public/
│   ├── brand/               # Logos, wordmark, banners, QR, favicons, OG image
│   └── projects/            # Portfolio project photography (web-optimised JPGs)
└── src/
    ├── main.js              # Data rendering + all interactions
    └── styles/
        ├── base.css         # Design tokens, reset, header, hero, marquee
        ├── sections.css     # About, services, projects, lightbox, contact, footer
        └── responsive.css   # Breakpoints & reduced-motion handling
```
